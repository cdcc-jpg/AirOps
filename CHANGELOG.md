## [v1.1.0] - 2026-07-25

### 🚀 Added
- **BFO 2020 Upper-Ontology Mapping Architecture**: Mapped `AirsoftField` and domain entities to Basic Formal Ontology (BFO 2020) concepts (`bfo:Site`, `bfo:Role`, `bfo:SpatialRegion`).
- **Polyhierarchy Display Optimization**: Resolved duplicate node display glitches in schema trees when classes inherit from multiple parent branches.
- **Standalone Alignment Module Export**: Decoupled visual alignment tooling into the dedicated, standalone **Weaver** repository (`cdcc-jpg/Weaver`).
